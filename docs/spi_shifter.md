# SPI Shifter

## Overview

The **SPI Shifter** module is responsible for handling serial data transmission and reception in the APB Based SPI Master Core.

It performs:

- Parallel-to-Serial conversion for MOSI transmission
- Serial-to-Parallel conversion for MISO reception
- MSB-first and LSB-first transfers
- Support for all four SPI modes (Mode 0–3)
- Synchronization with clock-enable signals generated by the Serial Clock Generator

The module acts as the data path of the SPI Master and interfaces directly with the SPI Control Logic and Serial Clock Generator.

                        +----------+-----------+

## Functional Description

### Transmit Path (MOSI)

When `send_data_i` is asserted:

```verilog
shift_register_s <= data_mosi_i;
```

the transmit data is loaded into the internal shift register.

Based on the configured bit order:

### LSB First

```text
Bit0 → Bit1 → Bit2 → Bit3 → Bit4 → Bit5 → Bit6 → Bit7
```

### MSB First

```text
Bit7 → Bit6 → Bit5 → Bit4 → Bit3 → Bit2 → Bit1 → Bit0
```

Data is shifted out on:

```verilog
mosi_o
```

using clock-enable signals generated by the Serial Clock Generator.

---

## Receive Path (MISO)

Incoming serial data is sampled from:

```verilog
miso_i
```

and stored into the internal receive register.

### LSB First Reception

```text
temp_reg_s[0]
temp_reg_s[1]
...
temp_reg_s[7]
```

### MSB First Reception

```text
temp_reg_s[7]
temp_reg_s[6]
...
temp_reg_s[0]
```

Received data becomes available on:

```verilog
data_miso_o
```

when:

```verilog
receive_data_i = 1
```

---

## SPI Mode Support

The SPI Shifter supports all standard SPI operating modes.

| SPI Mode | CPOL | CPHA | Operation Edge |
|-----------|------|------|---------------|
| Mode 0 | 0 | 0 | Rising Edge |
| Mode 1 | 0 | 1 | Falling Edge |
| Mode 2 | 1 | 0 | Falling Edge |
| Mode 3 | 1 | 1 | Rising Edge |

Clock edge selection is determined using:

```verilog
use_sclk0 = ((!cpha_i && cpol_i) ||
             ( cpha_i && !cpol_i));
```

### Edge Selection

| use_sclk0 | Edge |
|------------|------|
| 0 | Rising Edge |
| 1 | Falling Edge |

---

## Reset Behavior

When:

```verilog
PRESET_n = 0
```

the module resets:

```verilog
shift_register_s <= 8'h00;
temp_reg_s       <= 8'h00;
mosi_o           <= 1'b0;
```

and all internal counters are initialized.
